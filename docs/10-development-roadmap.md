## Phase 0: 프로젝트 설정

### 목표
개발 환경 구축 및 기본 설정

### 작업 항목

| 작업 | 내용 | 우선순위 |
|------|------|----------|
| Supabase 프로젝트 생성 | 프로젝트, DB, Storage 설정 | P0 |
| shadcn/ui 설치 | UI 컴포넌트 라이브러리 설정 | P0 |
| Resend 계정 설정 | 이메일 발송 서비스 | P1 |
| Vercel 프로젝트 연결 | 배포 환경 설정 | P1 |
| GitHub Actions 설정 | CI/CD 파이프라인 | P2 |

### 완료 기준
- [ ] Supabase 로컬 개발 환경 작동
- [ ] shadcn/ui 컴포넌트 사용 가능
- [ ] Vercel에 배포 가능
- [ ] `.env.example` 기반 환경 변수 설정 완료

## Phase 1: 인증 및 권한

### 목표
Supabase Auth 기반 사용자 인증/인가 구현

### 작업 항목

| 작업 | 내용 | 우선순위 |
|------|------|----------|
| DB 스키마 | roles, user_roles, user_companies 테이블 | P0 |
| RLS 정책 | 테이블별 RLS 정책 작성 | P0 |
| 인증 구현 | 로그인/로그아웃, 세션 관리 | P0 |
| 권한 검증 | 역할별 권한 확인 미들웨어 | P0 |
| 사용자 초대 | 관리자가 사용자 생성/초대 기능 | P1 |

### API 엔드포인트

| 경로 | 메서드 | 설명 |
|------|--------|------|
| `/auth/login` | POST | 로그인 |
| `/auth/logout` | POST | 로그아웃 |
| `/auth/callback` | GET | Supabase 콜백 |
| `/api/auth/session` | GET | 세션 확인 |
| `/api/admin/users` | POST | 사용자 생성 (admin) |
| `/api/admin/users/[id]/role` | PUT | 역할 변경 (super_admin) |

### 완료 기준
- [ ] company_user, individual_user, admin, super_admin 로그인 가능
- [ ] 역할별 적절한 화면 접근 제어
- [ ] RLS 정책으로 기업 데이터 격리
- [ ] 세션 만료 시 자동 로그아웃

## Phase 2: 예산관리

### 목표
예산서 작성, 제출, 승인 워크플로우 구현

### 작업 항목

| 작업 | 내용 | 우선순위 |
|------|------|----------|
| DB 스키마 | budgets, budget_items, budget_changes | P0 |
| 예산서 작성 | 항목 추가, 수정, 삭제 | P0 |
| 예산서 제출 | 제출, 상태 변경 | P0 |
| 관리자 검토 | 검토 의견, 승인/반려 | P0 |
| 예산 변경 | 변경 이력, 비교 기능 | P1 |
| 집행 현황 | 집계 조회 | P1 |

### API 엔드포인트

| 경로 | 메서드 | 설명 |
|------|--------|------|
| `/api/budgets` | GET | 목록 조회 |
| `/api/budgets` | POST | 생성 |
| `/api/budgets/[id]` | GET | 상세 조회 |
| `/api/budgets/[id]` | PUT | 수정 |
| `/api/budgets/[id]/submit` | POST | 제출 |
| `/api/budgets/[id]/review` | POST | 검토 시작 |
| `/api/budgets/[id]/approve` | POST | 승인 |
| `/api/budgets/[id]/request-revision` | POST | 보완 요청 |
| `/api/budgets/[id]/reject` | POST | 반려 |

### 화면

| 경로 | 설명 |
|------|------|
| `/portal/budgets` | 예산서 목록 |
| `/portal/budgets/new` | 예산서 작성 |
| `/portal/budgets/[id]` | 예산서 상세 |
| `/admin/budgets/[id]/review` | 관리자 검토 화면 |

### 완료 기준
- [ ] 기업 사용자가 예산서 작성/제출 가능
- [ ] 관리자가 예산서 승인/반려 가능
- [ ] 예산 변경 이력 추적 가능
- [ ] 집행 현황 실시간 조회
